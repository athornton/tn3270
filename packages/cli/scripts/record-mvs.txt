# MVS 3.8j TK5 (Update 5) recording script — TSO logon through ISPF and back out.
#
# STATUS: this script will NOT work yet. It is the target sequence, transcribed from
# a real working `zti` session (2026-08-17), and it is checked in so the Query Reply
# work has a concrete acceptance test. Running it today gets as far as the VTAM logon
# panel and then fails; see "WHY IT FAILS" below.
#
# Substitute HOST:PORT. On the machine this was captured from, TK5 is on
# localhost:3271 because VM/370 holds 3270 — check, do not assume.
#
# READ the ScreenText output. An `ok` status line only means the command was
# accepted, not that the host did what you wanted.
#
# CREDENTIALS: HERC02/CUL8TR, from TK5's own manual
# (doc/MVS_TK4-_v100_Users_Manual.pdf, "Logon to TSO"). HERC01 also works and is
# more privileged; HERC03/HERC04 use PASS4U; IBMUSER/IBMPASS is recovery-only.
# The password below appears in any trace in EBCDIC — redact before committing a
# fixture, per docs/live-testing.md step 4.
#
# ---------------------------------------------------------------------------
# WHY IT FAILS TODAY
#
# TSO here rejects the terminal type we hardcode (`IBM-3278-2`) and never sends us
# the Read Partition (Query) it sends clients that claim extended data stream. Our
# session dies with IKT00405I SCREEN ERASURE CAUSED BY ERROR RECOVERY PROCEDURE.
# Two things are needed, in this order:
#
#   1. Answer Read Partition (Query) — bytes in
#      packages/fixtures/x3270/tso-query-reply.txt.
#   2. Advertise a terminal type TSO accepts (`IBM-3278-2-E` suffices).
#
# Doing 2 without 1 moves the failure rather than fixing it. Full write-up in
# docs/live-testing.md.
#
# ---------------------------------------------------------------------------
# THE GEOMETRY TRAP, which this script deliberately does not paper over.
#
# In the captured session the screen size CHANGED MID-SESSION: 24x80 for the
# Hercules banner and VTAM logon panel, then 27x132 from the password prompt
# onwards, then back to 24x80 after logoff. That 27x132 was not TSO's idea — `zti`
# advertised it, derived from the operator's 171x41 terminal window
# (tnz/tnz.py:265-282 picks 27x132 for >=27 rows and >=132 columns), and TSO simply
# used what the client offered.
#
# So this sequence implies alternate-size support: a client that answers the Query
# with 24x80 should stay 24x80 throughout, and one that offers more must handle the
# host addressing beyond 1920 cells. Stage 1 reports an out-of-range address as a
# program check, which is the honest failure. Do not "fix" that by wrapping.
# ---------------------------------------------------------------------------
Trace(on)
Connect(HOST:PORT)
Wait(3270Mode,25)
# First connection to a terminal address after IPL shows the Hercules banner, which
# is entirely protected — RESET then CLEAR gets the VTAM logon panel. On later
# connections the panel appears directly and the Clear is harmless. This is TK5's
# own documented procedure, not a guess.
Wait(Settle,20)
ScreenText
Reset
Clear
Wait(Settle,20)
ScreenText
# The VTAM USS panel has exactly one unprotected field, at SBA(1770) with IC on it,
# right after "Logon ===>". Type the BARE USERID here. `TSO` and `LOGON HERC02` both
# draw INPUT NOT RECOGNIZED from the USS table.
String("HERC02")
Enter
Wait(Settle,25)
ScreenText
# "ENTER CURRENT PASSWORD FOR HERC02-". In the captured session the screen became
# 27x132 at exactly this point.
String("CUL8TR")
Enter
Wait(Settle,30)
ScreenText
# LOGON IN PROGRESS, then the "Welcome to the TSO system on TK5R" banner, ending in
# TSO's *** more-output prompt. Enter clears it.
Enter
Wait(Settle,25)
ScreenText
# A fortune cookie, and another ***.
Enter
Wait(Settle,25)
ScreenText
# ISPF starts automatically from this account's ISPLOGON proc — we do not type
# "ISPF". Expect the primary option menu, with USERID: HERC02 and TERMINAL: 3277.
# Reaching this panel is the real proof of a working session.
ScreenJson
# X at the Option prompt exits ISPF ("Enter END command to terminate ISPF").
String("X")
Enter
Wait(Settle,25)
ScreenText
# "CLST020 LIST data set not allocated", then the bare TSO READY prompt.
String("LOGOFF")
Enter
Wait(Settle,25)
# "HERC02 LOGGED OFF TSO", then ****** and the VTAM panel again at 24x80.
ScreenText
TraceText
Trace(off)
Quit
