# VM/370 R6 (VM/CE 1.2) recording script.
#
# Substitute HOST:PORT for your Hercules listener. Verified against VM/CE 1.2 on
# localhost:3270 with the unprivileged account CMSUSER.
#
# READ the ScreenText output. A status line saying "ok" only means the command was
# accepted, not that the host did what you expected — check the panels.
#
# Note the Wait(InputField) calls rather than Wait(Output): VM sends one logical
# screen as several records, and only the last carries the IC that places the
# cursor in a field. Wait(Output) fires on the first record and Wait(Unlock) can
# return before any of them.
#
# CREDENTIALS: the password typed below appears in the trace in EBCDIC. Redact it
# before committing any fixture derived from this run — see docs/live-testing.md.
Trace(on)
Connect(HOST:PORT)
Wait(3270Mode,20)
Wait(InputField,25)
ScreenText
String("LOGON CMSUSER")
Enter
Wait(InputField,25)
ScreenText
String("CMSUSER")
Enter
Wait(Unlock,30)
ScreenText
ScreenJson
Enter
Wait(Unlock,30)
ScreenText
String("QUERY TERMINAL")
Enter
Wait(Unlock,25)
ScreenText
String("LOGOFF")
Enter
Wait(Unlock,20)
ScreenText
TraceText
Trace(off)
Quit
