# @tn3270/canvas

Internal to the tn3270 client: the canvas renderer, glyph atlas, hit-testing and the
keypad/keyboard/transfer UI shared by the GUI and the web gateway. It has no stable
public API and is not meant to be depended on directly — use one of the front ends
instead: `@tn3270/gui` or `@tn3270/web`. See https://github.com/athornton/tn3270#readme.
