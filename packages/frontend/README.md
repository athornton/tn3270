# @tn3270/frontend

Internal to the tn3270 client: argument parsing, keymap and session wiring shared by the
CLI, TUI, GUI and web front ends. It has no stable public API and is not meant to be
depended on directly — use one of the front ends instead: `@tn3270/cli`, `@tn3270/tui`,
`@tn3270/gui`, or `@tn3270/web`. See https://github.com/athornton/tn3270#readme.
