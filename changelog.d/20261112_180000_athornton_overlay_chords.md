### Bug fixes

- The TUI's special-keys list (`Ctrl-K`) now shows the chord for every key the TUI binds: `F2`
  beside PF2, `Shift-F2` beside PF14, and so on through PF24. Twenty bound PF keys used to show a
  blank chord, as if they had none. Only Sys Req and Newline, which no key sends, are blank now.
